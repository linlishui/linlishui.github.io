Android开发者接手iOS存量项目：Objective-C快速入门

对 Android 开发者来说，接手 Objective-C 存量项目的难点通常不是业务逻辑，而是三套陌生表达同时出现： Objective-C 的消息发送语法 UIKit 的页面与事件模型 Xcode 的工程、依赖和签名体系 最有效的入门方式不是从 C 语言重新学起，而是先建立 Android 与 iOS 的概念映射，再用 Java 语法经验理解 Objective-C，最后通过一个可运行的 UIKit 小项目把知识串起来。 本文的目标不是全面讲解 Objective-C，而是帮助 Android 开发者尽快做到： 看懂常见 Objective-C 业务代码 找到 iOS 应用入口和页面入口 修改一个 UIKit 列表页面 理解 delegate、Block 和 ARC 避开接手老项目时的常见坑 先建立平台映射 Android 和 iOS 的框架不能完全等价，但下面的映射可以帮助建立第一印象。 Android iOS存量项目 说明 Application AppDelegate、SceneDelegate 应用和场景生命周期 Activity、Fragment UIViewController 页面控制器，不能完全等价 View、ViewGroup UIView UI 基础对象 XML Layout Storyboard、XIB 可视化页面文件 ConstraintLayout Auto Layout 约束布局 RecyclerView UITableView、UICollectionView 列表和网格 RecyclerView.Adapter UITableViewDataSource 提供列表数据 OnClickListener target-action、delegate、Block 事件回调 interface protocol 能力约束 lambda Block 可传递的代码块 AndroidManifest.xml Info.plist、Entitlements 配置和权限声明 applicationId Bundle Identifier 应用唯一标识 Gradle Module Xcode Target 构建单元，语义并不完全相同 Handler主线程调度 Main Queue 主线程任务调度 这些概念只适合粗略类比。例如 UIViewController 同时参与视图管理、页面生命周期和导航协作，不能简单看作另一个 Activity。 ...
